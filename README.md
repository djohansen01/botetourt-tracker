# Botetourt County Transparency Dashboard

A community-maintained web app tracking Botetourt County, Virginia government spending, budgets, and elected officials. Deployable as a static site via **GitHub Pages** with a daily Python scraper running on a **Digital Ocean** Ubuntu droplet.

---

## What it does

| Component | Purpose |
|---|---|
| `scraper.py` | Scrapes botetourtva.gov (Finance, Agenda Center, homepage) and the Virginia APA audit page. Outputs `data.json` and `changelog.json`. |
| `index.html` | Static community dashboard (vanilla JS, no framework). Reads `data.json` at load time. Deployable to GitHub Pages. |
| `cron_setup.sh` | Installs a daily cron job on a Digital Ocean Ubuntu droplet. Auto-commits updated data back to the repo so GitHub Pages stays fresh. |

## Quick start (local preview)

```bash
# 1. Clone the repo
git clone https://github.com/YOUR-ORG/botetourt-tracker.git
cd botetourt-tracker

# 2. Run the scraper (Python 3.9+ stdlib only — no pip install needed)
python3 scraper.py

# 3. Serve locally
python3 -m http.server 8000
# Open http://localhost:8000
```

## GitHub Pages deployment

### 1. Create the repository

```bash
gh repo create botetourt-tracker --public --source=. --remote=origin --push
```

### 2. Enable GitHub Pages

In the repo on GitHub:  
**Settings → Pages → Source → Deploy from a branch → `main` / `(root)`**

The dashboard will be live at:  
`https://YOUR-ORG.github.io/botetourt-tracker/`

### 3. Commit initial data

```bash
python3 scraper.py
git add data.json changelog.json
git commit -m "feat: initial scrape"
git push
```

GitHub Pages will automatically serve the updated `data.json` on each push.

## Digital Ocean — automated daily scraping

### Prerequisites

- Ubuntu 22.04+ droplet (the $4/mo basic tier is sufficient)
- SSH access to the droplet
- Python 3 installed (`sudo apt install python3`)

### 1. Set up the droplet

```bash
# On the droplet — create a dedicated user (optional but recommended)
sudo adduser botetourt
sudo su - botetourt

# Clone the repo
git clone https://github.com/YOUR-ORG/botetourt-tracker.git /opt/botetourt-tracker
cd /opt/botetourt-tracker
```

### 2. Configure Git push access

The cron job commits updated `data.json` back to GitHub to keep Pages fresh.

```bash
# Option A: SSH deploy key (recommended)
ssh-keygen -t ed25519 -C "botetourt-bot" -f ~/.ssh/botetourt_deploy -N ""
# Add the PUBLIC key to GitHub repo → Settings → Deploy keys (allow write access)

# Verify
ssh -T git@github.com

# Option B: GitHub Personal Access Token
git remote set-url origin https://YOUR_TOKEN@github.com/YOUR-ORG/botetourt-tracker.git
```

### 3. Run cron_setup.sh

```bash
cd /opt/botetourt-tracker
REPO_DIR=/opt/botetourt-tracker bash cron_setup.sh
```

This will:
- Write a wrapper script to `/usr/local/bin/botetourt-scrape`
- Install a cron entry to run at **06:30 UTC daily**
- Set up log rotation at `/var/log/botetourt-tracker/scraper.log`

**Customize the schedule:**
```bash
CRON_HOUR=8 CRON_MIN=0 bash cron_setup.sh   # run at 8:00 AM UTC instead
```

### 4. Test the setup

```bash
# Run manually and check logs
botetourt-scrape
tail -30 /var/log/botetourt-tracker/scraper.log

# Confirm cron entry installed
crontab -l
```

```bash
echo ".scraper_hashes.json" >> .gitignore
```

## Keeping data fresh

The scraper uses a hash file (`.scraper_hashes.json`) to detect newly published documents. Each daily run:

1. Fetches Finance, Agenda Center, county homepage, and Virginia APA
2. Compares document URLs against previous run
3. Appends any new items to `changelog.json`
4. Commits and pushes `data.json` + `changelog.json` → GitHub Pages auto-updates
